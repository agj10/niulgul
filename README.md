# niulgul

사진 조각을 재배치해 원하는 얼굴을 만드는 웹 도구.

## 실행

Node.js 22 이상에서 실행해요.

```sh
npm ci
npm run dev
```

빌드는 `npm run build`, 로컬 미리보기는 `npm start`로 실행해요.

## 사용

1. 재료 사진과 얼굴 사진을 선택해요. 카메라는 촬영 버튼으로 사진을 넣어요.
2. 적용 영역과 설정을 고른 뒤 **변환하기**를 눌러요.
3. 결과를 PNG 또는 GIF로 저장해요.

결과 해상도는 재료 사진 기준이에요. 사진은 브라우저 안에서만 처리해요.
